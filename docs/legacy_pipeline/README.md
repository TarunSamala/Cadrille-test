# Legacy pipeline

These documents and diagrams predate the Project Bible v1.0. Their phase names
are retained for reproducibility and backtracking, but they are not the current
development authority.

## Historical sequence

| Legacy stage | Historical meaning | Current use |
| --- | --- | --- |
| Phase 1 | Normalization, silhouettes, edges and image measurements | Proposal evidence for Bible Phase 1 review |
| Phase 2 / 2.2 | Segmentation and mask refinement | Proposal evidence only |
| Phase 2.3 | Detail, relief and semantic proposal extraction | Research evidence only |
| Phase 3 / 3.2 | Coarse/non-metric reconstruction and topology correction | Historical geometry checkpoint |
| Phase 3.3 | Ring01 multi-view exact-solid refinement | Historical validated Ring01 checkpoint |
| Phase 3.3.1 | Four individually addressable curved claws | Historical validated Ring01 checkpoint |
| Phase 3.3.2 | Four-claw oblique-preview visibility correction | Historical presentation correction |

There is no one-to-one numeric mapping between these labels and Bible phases.
For example, legacy Phase 3.3 is not Bible Phase 3. Bible Phase 3 is a measured
camera/depth/normal/geometry evidence benchmark.
